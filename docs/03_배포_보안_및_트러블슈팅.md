# 03. 배포, 보안 및 트러블슈팅

## 1. 배포 과정 (GitHub + Vercel)

1. 프로젝트를 GitHub 저장소에 push
2. https://vercel.com 에 GitHub 계정으로 로그인
3. **Add New → Project** → 저장소 **Import**
4. Framework Preset: **Other** (그대로)
5. **Environment Variables**에 `GEMINI_API_KEY` 추가
6. **Deploy** → 발급된 `https://...vercel.app` 주소로 접속 확인
7. 이후에는 코드를 고치고 `git push`만 하면 Vercel이 자동으로 재배포

## 2. 로컬 환경 vs 배포 환경

| 구분 | 로컬 | 배포(Vercel) |
|---|---|---|
| 주소 | `localhost:3000` (`vercel dev`) | `https://...vercel.app` |
| API 키 위치 | `.env` 파일 (GitHub에 안 올라감) | Vercel 환경 변수 |
| 백엔드 실행 | 내 컴퓨터가 흉내 | 요청이 올 때마다 Vercel이 함수 실행 |
| 수정 반영 | 저장하면 바로 | `git push` → 자동 재배포 (1분 내외) |
| `index.html` 직접 열기 | 화면은 보이지만 AI 기능은 안 됨 (`/api` 서버 없음) | 전체 동작 |

## 3. API 키 보안 원칙

- 키는 **Vercel 환경 변수**와 내 컴퓨터의 `.env`에만 둔다.
- `.env`는 `.gitignore`에 등록되어 있어 GitHub에 올라가지 않는다. (`.env.example`에는 가짜 값만)
- 코드·README·스크린샷·대화 로그 캡처에 키가 보이지 않게 한다.
- AI 호출은 무료 할당량/과금이 있으므로, 입력 길이 제한·요청 중 버튼 비활성화로 불필요한 호출을 줄인다.

### 키가 유출됐다고 의심될 때

1. Google AI Studio(https://aistudio.google.com/apikey)에서 해당 키 **삭제**
2. 새 키 발급
3. Vercel → Settings → Environment Variables에서 값 교체 → **Redeploy**
4. 실수로 키를 커밋했다면, 키 폐기가 1순위이고 그다음 커밋 이력에서 제거 (예: `git filter-repo` 또는 BFG Repo-Cleaner) 후 강제 push

## 4. 트러블슈팅 기록

| 증상 | 원인 | 해결 |
|---|---|---|
| 배포 후 첫 테스트에서 "알 수 없는 오류가 발생했어요" | Vercel 환경 변수에 붙여넣은 API 키에 눈에 보이지 않는 문자가 섞인 것으로 추정. 한글·특수 공백이 HTTP 헤더에 들어가면 파이썬이 `UnicodeEncodeError`를 냄 (로컬에서 같은 상황을 재현해 확인) | ① 키 앞뒤 공백 자동 제거 ② 키에 한글·보이지 않는 문자가 있으면 원인을 화면에 안내 ③ 그 밖의 오류는 오류 종류 이름을 함께 표시하고 상세 내용은 Vercel 로그에 기록 ④ AI Studio의 복사 버튼으로 키를 다시 넣고 재배포 → 정상 동작 |
| 코스 결과의 "코스 복사" 버튼 글자가 두 줄로 깨짐 | 제목이 길면 버튼 폭이 줄어듦 | 버튼 글자 줄바꿈 금지(`white-space: nowrap`) |
| "서버에 AI API 키가 설정되지 않았어요" | Vercel 환경 변수 미설정, 또는 설정 후 재배포 안 함 | 환경 변수 저장 → Deployments → Redeploy |
| "잠시 후 다시 시도해주세요" (429) | Gemini 무료 요금제 하루 할당량 초과 (이전 과제 테스트 중 실제로 겪음) | 할당량은 프로젝트·모델 단위로 계산되고 태평양 시간 자정(한국 오후 4~5시)에 초기화 → 여러 모델로 자동 전환하도록 개선 |
| 로컬에서 버튼을 눌러도 아무 결과가 없음 | `index.html`을 파일로 직접 열어서 `/api/recommend`가 없음 | 배포 URL 또는 `vercel dev`로 테스트 |
| 모바일에서 메뉴가 화면을 가림 | 메뉴 클릭 후에도 열린 상태 유지 | 메뉴 항목 클릭 시 자동으로 닫히도록 수정 |
| 필수값 경고가 입력 후에도 남아 있음 | 경고 문구를 제출 시에만 갱신 | 입력할 때마다 검사해서 모두 채워지면 문구 제거 |

## 5. 배포 후 확인 체크리스트

- [ ] PC 브라우저에서 4개 메뉴 이동이 모두 됨
- [ ] 모바일 화면(휴대폰 또는 개발자 도구 모바일 보기)에서 햄버거 메뉴·폼이 깨지지 않음
- [ ] 빈 값으로 버튼 → "필수값을 입력해주세요" 표시
- [ ] 정상 입력 → 코스 타임라인 표시
- [ ] 다크 모드 버튼 → 색상 전환, 새로고침해도 유지
- [ ] GitHub 저장소에 `.env`가 없음
