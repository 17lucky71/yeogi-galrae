# 01. 서비스 기획서 — 여기갈래?

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 여기갈래? |
| 한 줄 소개 | 조건만 고르면 AI가 시간대별 국내 여행 코스를 짜주는 웹 서비스 |
| 목적 | 여행 계획을 세울 때 블로그·지도 앱을 오가며 몇 시간씩 검색하는 수고를 줄이고, 1분 안에 "바로 따라갈 수 있는 코스 초안"을 제공한다 |
| 타겟 사용자 | ① 주말에 즉흥적으로 국내 여행을 떠나는 20~30대 직장인 ② 친구·연인·가족과의 여행 일정을 대신 짜야 하는 "총무" 역할의 사람 ③ 처음 가보는 지역이라 무엇부터 봐야 할지 모르는 사람 |
| 제공 가치 | 검색 시간 절약, 동행·취향에 맞춘 맞춤 코스, 친구에게 바로 공유 가능한 텍스트 복사 |

## 2. 페이지 / 섹션 구성

한 페이지 안에 4개 섹션을 두고, 상단 고정 메뉴로 이동한다. (모바일에서는 햄버거 메뉴)

| 섹션 | 역할 | 주요 요소 |
|---|---|---|
| 홈 (Hero) | 서비스가 무엇인지 3초 안에 전달 | 캐치프레이즈, "코스 추천받기" 버튼, 예시 코스 카드 |
| 서비스 소개 | 사용 방법 안내 | 3단계 카드 (조건 고르기 → AI 코스 설계 → 확인·복사) |
| AI 코스 추천 | 핵심 기능 | 입력 폼, 결과 패널(빈 상태/로딩/오류/결과) |
| 자주 묻는 질문 | 불안 요소 해소 | 정확도, 해외 지역, 오류 메시지, 개인정보 저장 여부 |

메뉴 이동 방식: `<a href="#섹션id">` 앵커 링크 + 부드러운 스크롤. 스크롤 위치에 따라 현재 섹션 메뉴를 강조한다.

## 3. 핵심 기능

1. **AI 여행 코스 추천** (AI API 연동)
2. 반응형 레이아웃 (데스크톱 / 태블릿 / 모바일)
3. 다크 모드 (보너스: 사용성 개선)
4. 추천 결과 텍스트 복사

## 4. AI 기능 설계

### 입력

| 항목 | 형식 | 필수 | 제한 |
|---|---|---|---|
| 여행 지역 | 텍스트 | ✔ | 30자 이내 |
| 여행 기간 | 선택 (당일치기 / 1박 2일 / 2박 3일) | ✔ | 목록 외 값 거부 |
| 동행 | 선택 (혼자 / 친구 / 연인 / 가족) | ✔ | 목록 외 값 거부 |
| 여행 스타일 | 체크박스 (맛집, 자연, 역사·문화, 카페, 액티비티, 쇼핑) | | 최대 5개 |
| 추가 요청 | 여러 줄 텍스트 | | 200자 이내 |

### 출력

```json
{
  "title": "코스 제목",
  "summary": "코스 한 줄 소개",
  "days": [
    { "day": 1, "theme": "그날의 테마",
      "items": [ { "time": "09:00", "place": "장소", "description": "추천 이유" } ] }
  ],
  "tips": ["교통/준비물 팁"]
}
```

화면에는 일자별 타임라인(DAY 배지 + 시간 + 장소 + 설명)과 여행 팁 박스로 표시한다.

### 사용자에게 주는 가치

- "어디부터 가야 하지?"를 해결하는 **시간 순서 코스**
- 동행/스타일을 반영한 **추천 이유** 제공
- 버튼 하나로 **복사해서 단톡방에 공유**

### 실패 처리 기준

| 상황 | 감지 위치 | 사용자 안내 |
|---|---|---|
| 빈 입력 (필수값 누락) | 프론트 (전송 전) + 백엔드 재검증(400) | "필수값을 입력해주세요: 여행 지역, …" + 해당 칸 빨간 테두리 |
| 입력이 너무 김 | 프론트 maxlength + 백엔드(400) | "추가 요청은 200자 이내로 입력해주세요." |
| AI 사용량 초과 (429) | 백엔드 | 다른 모델로 자동 전환 → 모두 실패 시 "잠시 후 다시 시도해주세요." |
| API 키 누락/인증 오류 | 백엔드 (500) | "서버 설정에 문제가 있어요. 관리자에게 알려주세요." |
| AI 응답 형식 오류 | 백엔드 | 더 엄격한 프롬프트로 1회 재시도 → 실패 시 502 "다시 시도해주세요." |
| 응답 지연 | 프론트 | 8초 경과 시 "생각보다 오래 걸리고 있어요" 문구로 변경 |
| 타임아웃 | 프론트 30초 / 백엔드 모델별 20초 | "응답 시간이 30초를 넘었어요. 다시 시도해주세요." + 다시 시도 버튼 |
| 예상 못한 오류 | 백엔드 | 내부 오류 내용은 숨기고 "알 수 없는 오류가 발생했어요." |

## 5. 테스트 시나리오

| 입력 | 기대 결과 |
|---|---|
| 강릉 / 1박 2일 / 친구 / 맛집, 자연 | DAY 1, DAY 2 타임라인과 팁이 표시됨 |
| (지역 빈칸) / 당일치기 / 혼자 | 전송되지 않고 "필수값을 입력해주세요: 여행 지역" 표시 |
| 전주 / 당일치기 / 가족 / 추가 요청 200자 가득 | 코스가 표시되거나, 늦어지면 지연 안내 문구 표시 |
| 파리 / 2박 3일 / 연인 | 국내 비슷한 여행지로 대체 추천하고 summary에 안내 |
| 할당량 초과 상태 | "잠시 후 다시 시도해주세요" + 다시 시도 버튼 |

## 6. 보안 / 운영

- API 키는 Vercel 환경 변수(`GEMINI_API_KEY`)로만 관리하고, 브라우저 코드·README·스크린샷에 노출하지 않는다.
- 브라우저는 우리 서버의 `/api/recommend`만 호출하므로 사용자가 개발자 도구를 열어도 키를 볼 수 없다.
- 무료 요금제 할당량을 고려해 입력 길이를 제한하고, 버튼 연타를 막기 위해 요청 중에는 버튼을 비활성화한다.
- 키 유출 의심 시: AI Studio에서 키 삭제 → 새 키 발급 → Vercel 환경 변수 교체 → 재배포.
